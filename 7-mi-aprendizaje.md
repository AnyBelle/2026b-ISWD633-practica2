# COMPLETAR  
### Principales aprendizajes logrados
Antes de realizar la práctica, tenía conocimientos básicos sobre la creación y ejecución de contenedores, pero no comprendía claramente cómo controlar sus recursos ni cómo construir imágenes propias. Después de realizar los ejercicios, aprendí a establecer límites de memoria RAM y CPU, diferenciar la memoria RAM de la memoria swap y reconocer cómo estas restricciones ayudan a administrar los recursos del computador.
También aprendí a interpretar las instrucciones de un Dockerfile, como FROM, RUN, COPY, EXPOSE y CMD. Construí una imagen con la etiqueta 1.0 y comprendí cómo generar una nueva versión después de modificar el archivo index.html. Además, identifiqué que Docker reutiliza la caché de las instrucciones que no cambian, lo que reduce el tiempo de construcción. Otro aprendizaje fue la diferencia entre publicar puertos con -p y con -P. Comprendí que -P asigna automáticamente puertos del host a los declarados en la imagen y que puedo consultar ese mapeo con docker port. También conocí las imágenes huérfanas, las políticas de reinicio y las comprobaciones de salud de los contenedores.

### Problemas y ajustes documentados
Durante la práctica, se presentó un error al ejecutar yum update, debido a que los repositorios originales de CentOS 7 ya no estaban disponibles. Para lo cual, modifiqué el Dockerfile para utilizar los repositorios archivados de CentOS Vault y agregué -y a los comandos de actualización e instalación para aceptar las confirmaciones automáticamente. Después de estos ajustes, la imagen se construyó correctamente.
Además, aclaré que la carpeta web y el archivo index.html debían existir en mi computador antes de construir la imagen, porque la instrucción COPY utiliza esos archivos como origen. Esto me ayudó a comprender la diferencia entre los archivos locales y el contenido que Docker incorpora dentro de la imagen.
